<h1> Needs </h1>

1. Install Python and pip - https://phoenixnap.com/kb/how-to-install-python-3-windows
2. Install GIT - https://www.youtube.com/watch?v=iYkLrXobBbA
3. Make a GitHub Account - https://github.com/
4. Install node.js - https://www.youtube.com/watch?v=NlC10atHTQc 
5. Clone the project - https://github.com/py39cptCiolacu/euroavia_voting_system
6. Create a new venv by going to /euroavia_voting_system and run: python -m venv .venv 
7. Go to /ui and run: npm install
8. In one cmd in /euroavia_voting_system activate the python venv bu running: .venv/Scripts/activate
9. In same cmd run: ptyhon main.py - This will start the backend
10. In another cmd in /ui run: npm start - This will start the frontend
11. App will be available at: localhost:3000
